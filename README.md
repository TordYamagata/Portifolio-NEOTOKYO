## 🔴 Sobre o projeto

**NEO-TOKYO PORTFOLIO** é um portfólio pessoal desenvolvido com HTML, CSS e JavaScript, inspirado na estética cyberpunk japonesa e no universo visual de **Akira (1988)**.

O projeto combina uma interface futurista, elementos industriais, cores marcantes, animações e interatividade para apresentar minhas habilidades e projetos como desenvolvedora em formação.

A proposta é fugir dos portfólios tradicionais e criar uma experiência visual com personalidade própria.

## 🚀 Como executar

**1. Clone o repositório:**

```bash
git clone https://github.com/TordYamagata/Portifolio-NEOTOKYO.git
```

**2. Acesse a pasta:**

```bash
cd Portifolio-NEOTOKYO
```

**3. Abra o projeto:**

Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** do Visual Studio Code.

Não é necessário instalar bibliotecas ou dependências adicionais.
